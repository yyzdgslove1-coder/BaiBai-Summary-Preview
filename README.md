# 柏宝书摘要预览

独立的 SillyTavern 扩展，配合原版柏宝书 1.3.5。在楼层面板手动生成摘要时，先查看、复制和编辑本次发给 AI 的正文。关闭扩展并刷新即可恢复原流程。

## 安装

原版柏宝书和它的设置都保持启用。在酒馆扩展管理的「安装扩展」里填入 `https://github.com/yyzdgslove1-coder/BaiBai-Summary-Preview`，选仅为当前用户安装，装完刷新酒馆。

## 使用

为柏宝书的摘要任务指派副 API 渠道。点某楼摘要按钮，已有摘要时先在柏宝书确认框里点「重新生成」。预览中编辑正文后点「发送并生成」。清空正文时无法发送。自定义模板缺少 `{{content}}` 时显示警告，可选「照常发送」。取消会结束本轮，柏宝书通常显示「已取消摘要生成」错误提示，上游内部重试会直接结束。

## 已知限制

- 自动摘要直接放行。通过楼层 shadow root 的按钮和重新生成确认框捕获手动操作，以该楼的忙碌指示限定操作生命周期。批量补摘、合并总结和检索重写均放行。
- 跟随主 API 走酒馆 `generateRaw`，可按主 API 类型变成聊天补全消息或文本补全提示词，缺少副 API 的固定握手字段。本版原样放行。预览仅支持 1.3.5 的副 API 字符串 JSON 请求。排除参数删掉识别字段时同样放行。
- 内置模板按代码固定材料标题定位正文。自定义模板按代码追加的档案标题识别，并对照当前保存的模板确定 `{{content}}` 展开范围。相邻宏或重复分隔符造成边界歧义时原样放行。多处 `{{content}}` 会一起替换。
- 预览期间忽略柏宝书原 signal，发送后按当前摘要渠道的 `timeoutSec` 重新计时，覆盖响应体读取。原版计时器无法由 fetch 层撤销，如果预览已超过原超时再取消，且重试次数设为零，柏宝书会显示它自己的超时错误。发送后的网络错误也可能被上游归类为超时。取消仍关闭预览且不发送请求。
- 第三方插件仍可继续处理本扩展交给它们的请求。上游更改按钮或材料结构后需要重新适配。
