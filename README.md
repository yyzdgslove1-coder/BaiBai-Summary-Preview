# 柏宝书摘要预览

独立的 SillyTavern 扩展，配合原版柏宝书 1.3.5。手动生成单楼摘要时，先查看、复制和编辑本次发给 AI 的正文。关闭扩展并刷新即可恢复原流程。

## 安装

原版柏宝书和它的设置都保持启用。在酒馆扩展管理的「安装扩展」里填入 `https://github.com/yyzdgslove1-coder/BaiBai-Summary-Preview`，选仅为当前用户安装，装完刷新酒馆。

## 使用

装好刷新后，在扩展面板里展开「柏宝书摘要预览」，能看到正在运行的版本、柏宝书版本和摘要渠道。

为柏宝书的摘要任务指派副 API 渠道。支持两个入口，在聊天楼层面板点摘要按钮，或打开柏宝书主界面，进入「摘要」页，点「未摘要楼层」中的楼层号。楼层面板已有摘要时先在柏宝书确认框里点「重新生成」。预览中编辑正文后点「发送并生成」。清空正文时无法发送。自定义模板缺少 `{{content}}` 时显示警告，可选「照常发送」。取消会结束本轮，柏宝书通常显示「已取消摘要生成」错误提示，上游内部重试会直接结束。

## 已知限制

- 自动摘要直接放行，不弹框、不提示。手动操作通过楼层摘要按钮、重新生成确认框或「未摘要楼层」按钮捕获。楼层面板入口观察该面板的忙碌指示，「未摘要楼层」入口观察主界面 shadow root 内目标按钮的旋转标记，聊天里无对应消息 DOM 或关闭楼层面板时仍可使用。批量补摘、合并总结和检索重写均放行。
- 跟随主 API 走酒馆 `generateRaw`，缺少副 API 的固定握手字段，仍原样放行。摘要没有指派副 API 渠道时，手动操作的忙碌标记出现过、结束时却未出现预览，会提示检查副 API 指派。已指派渠道却没有发出请求，说明柏宝书在发请求前自己停了，由柏宝书报错，本扩展不提示。看到副 API 单楼摘要请求却无法定位正文时，会提示已按原样发送。忙碌标记未出现的早退操作不提示。预览仅支持 1.3.5 的副 API 字符串 JSON 请求，排除参数删掉识别字段时同样放行。
- 内置模板按代码固定材料标题定位正文。自定义模板按代码追加的档案标题识别，并对照当前保存的模板确定 `{{content}}` 展开范围。相邻宏或重复分隔符造成边界歧义时原样放行。多处 `{{content}}` 会一起替换。
- 预览期间忽略柏宝书原 signal，发送后按当前摘要渠道的 `timeoutSec` 重新计时，覆盖响应体读取。原版计时器无法由 fetch 层撤销，如果预览已超过原超时再取消，且重试次数设为零，柏宝书会显示它自己的超时错误。发送后的网络错误也可能被上游归类为超时。取消仍关闭预览且不发送请求。
- 第三方插件仍可继续处理本扩展交给它们的请求。上游更改按钮或材料结构后需要重新适配。
